# Design doc errata (2026-09-08)

Corrections for `docs/design/2026-09-07-base-image.md` against the current tree.
Tracked in https://github.com/Dustpan95/DXBerry-Pi/issues/3.

## §3 User flow — missing/invalid `dxberry.txt`

**Was:** hostname `DietPi`, password `dietpi`  
**Is:** hostname `dxberry-pi` (from `boot/dietpi.overrides.txt` `AUTO_SETUP_NET_HOSTNAME`), password `dietpi` (stock DietPi `AUTO_SETUP_GLOBAL_PASSWORD`, not overridden).  
Matches `README.md` and `dxberry-preboot` error text.

## §6.2 DietPi overrides block

The quoted override list omitted keys that `boot/dietpi.overrides.txt` actually sets:

```
AUTO_SETUP_NET_ETHERNET_ENABLED=1
AUTO_SETUP_NET_WIFI_ENABLED=0
AUTO_SETUP_NET_HOSTNAME=dxberry-pi
```

## §11 Image build — decompress path

**Was:** `build/work/base.img`  
**Is:** `build/work/DXBerry-Pi-<version>-rpi234-arm64.img` (see `build/build-image.sh`)

## §12 CI/CD — test runner

**Was:** `bats tests/`  
**Is:** `tests/run.sh` (plain bash; §14 already says this)
